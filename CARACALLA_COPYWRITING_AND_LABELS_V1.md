## 1. Principes de wording

### 1.1 Règle fondamentale
**Parler comme le dirigeant pense, pas comme le consultant écrit.**

Un dirigeant de PME de 20 personnes ne dit pas "friction processuelle dans le pipeline commercial". Il dit "on perd du temps sur les devis".

### 1.2 Ce qu'on évite

| Pattern interdit | Exemple à ne pas faire | Pourquoi |
|-----------------|----------------------|----------|
| Jargon IA | "Notre algorithme d'intelligence artificielle analyse..." | Crée de la distance et de la méfiance |
| Promesses magiques | "Transformez votre entreprise grâce à l'IA" | Non crédible, non vérifiable |
| Vocabulaire consultant | "Optimisation des workflows opérationnels" | Incompréhensible pour la cible |
| Vocabulaire tech | "Pipeline de données", "API", "workflow engine" | Hors contexte dirigeant |
| Superlatifs | "La meilleure solution", "révolutionnaire" | Perte de crédibilité |
| Urgence artificielle | "Offre limitée", "Plus que 3 places" | Dark pattern |
| Passif | "Votre entreprise sera analysée" | Manque de clarté et d'agence |

### 1.3 Ce qu'on cherche

| Pattern visé | Exemple | Pourquoi |
|-------------|---------|----------|
| Mots métier | "devis", "relances", "planning", "fournisseurs" | C'est le vocabulaire du quotidien |
| Verbes concrets | "gagner du temps", "réduire les erreurs", "voir clair" | Orienté action et résultat |
| Conséquences mesurables | "3h/semaine perdues sur les relances manuelles" | Tangible et crédible |
| Formulations directes | "Vous ressaisissez vos devis à la main ?" | Le dirigeant se reconnaît |
| Ton sobre | "Voici ce que nous avons identifié." | Professionnel, pas marketing |

### 1.4 Règle de formulation
Pour chaque texte, se demander :
> "Est-ce qu'un dirigeant de PME de menuiserie à Bordeaux comprendrait cette phrase en la lisant une seule fois ?"

Si non, réécrire.

## 2. Taxonomie interne vs affichage externe

Caracalla utilise une taxonomie interne précise pour le moteur. L'affichage utilise un vocabulaire adapté.

| Concept interne | Affichage utilisateur |
|----------------|----------------------|
| `friction` | "Point de friction" ou "Difficulté identifiée" |
| `opportunity` | "Piste d'amélioration" ou "Opportunité" |
| `archetype` | "Profil opérationnel" |
| `severity_critical` | "Impact fort" |
| `severity_high` | "Impact significatif" |
| `severity_medium` | "Impact modéré" |
| `severity_low` | "Impact faible" |
| `feasibility_high` | "Mise en place rapide" |
| `feasibility_medium` | "Mise en place réaliste" |
| `feasibility_low` | "Mise en place complexe" |
| `risk_high` | "Risque élevé" |
| `risk_low` | "Risque maîtrisé" |
| `confidence_low` | "Données insuffisantes" |
| `confidence_high` | "Diagnostic fiable" |
| `pilot` | "Projet pilote" |
| `prerequisite` | "Prérequis" |
| `scoring` | "Évaluation" |

## 5. Exemples de micro-copy

### 5.1 Hints de formulaire (audit)

| Champ | Hint |
|-------|------|
| Secteur d'activité | "Ex : menuiserie, cabinet comptable, négoce de matériaux" |
| Nombre de salariés | "Comptez les CDI, CDD et intérimaires réguliers" |
| Outils de devis | "Ex : Excel, EBP, Sage, papier, autre logiciel" |
| Délai moyen devis | "De la demande client à l'envoi du devis" |
| Relances clients | "Comment relancez-vous les devis sans réponse ?" |
| Ressaisie | "Combien de fois la même info est saisie dans des outils différents ?" |
| Tableau de bord | "Avez-vous un endroit unique pour voir l'état de votre activité ?" |

### 5.2 Messages de progression

| Moment | Message |
|--------|---------|
| Début audit | "C'est parti. Répondez simplement — il n'y a pas de mauvaise réponse." |
| Mi-parcours | "Vous êtes à mi-chemin. Vos réponses commencent à dessiner votre carte." |
| Avant-dernière étape | "Presque terminé. Plus qu'une étape." |
| Audit terminé | "C'est fait. Votre synthèse est prête." |

### 5.3 Messages de confiance

| Contexte | Message |
|----------|---------|
| Score affiché | "Ce score est calculé à partir de vos réponses sur [thème]. Voici comment le lire : ..." |
| Données insuffisantes | "Nous n'avons pas assez d'éléments sur [thème] pour produire un diagnostic fiable." |
| Limite du gratuit | "La synthèse gratuite couvre les frictions principales. Le rapport complet ajoute les solutions, les coûts et le plan d'action." |

## 6. Règles de ton

### 6.1 Registre
- **Vouvoiement** systématique.
- Ton **sobre et professionnel**, jamais familier ni condescendant.
- Pas d'humour, pas d'émojis, pas de points d'exclamation.

### 6.2 Longueur
- Titres : 8 mots max.
- Sous-titres : 15 mots max.
- Descriptions : 2 phrases max.
- CTA : 5 mots max.

### 6.3 Structure des phrases
- Sujet + verbe + complément.
- Pas de double négation.
- Pas de phrases conditionnelles longues.
- Toujours dire ce que le produit fait, pas ce qu'il ne fait pas.
